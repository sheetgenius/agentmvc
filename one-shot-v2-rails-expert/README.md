# Rails expert diagnostic

This is a separately labelled, expert-guided Rails/Ruby condition on the
byte-identical shared [v2 prompt](../one-shot-v2-expert/PROMPT.md), measurement
rules, client, specification, security suite, and gates. It is not pooled with
the earlier one-shot or eight-step history. The guided Phoenix and TypeScript
tracks use the same prompt and measurement boundary.

The product-free Rails 8.1 scaffold contains PostgreSQL wiring, GoodJob's
database migration, a health route, raw WebSocket/JWT/password libraries, and
production packaging. It contains no Conduit user, article, share, export, or
room implementation. A measured agent will build the product in one isolated
directory with a fresh Codex home, no memory, no subagents, no interactive
approvals, and no access to the parent repo, siblings, or host Docker socket.

Rails is interpreted Ruby. Its production-appropriate package eager-loads the
application and precompiles Bootsnap caches; it is not described as a native
compiled binary. The coordinator verifies a fresh PostgreSQL boot and the
same development and production gates used by the other tracks.
