1: //! The app's own boot code in `config/initializers/*.rb`, run at boot on
2: //! the ruby family and spinel (E2 of rubys/roundhouse#841, for the host's
3: //! initializers).
4: //!
5: //! Rails `load`s every initializer once at boot, in path order, after the
6: //! app's classes are autoloadable. A statement no recognizer reads and
7: //! whose holder is the app itself (`initializer_ledger::Holder::App`) is
8: //! the app's code: a constant it assigns, a loop over files, a log line,
9: //! a call. Those become [`App::boot_program`], typed like `db/seeds.rb`
10: //! and emitted as top-level code that the tree's `boot.rb` loads last.
11: //!
12: //! A top-level `def` defines a private method on Object, callable from
13: //! every class. Here it becomes a class method of the synthesized
14: //! [`MODULE`], and each receiverless call to it names that module
15: //! (`apply_call_sites`), so every target reaches it as an ordinary typed
16: //! method.
17: //!
18: //! Left to the ledger, as warnings: statements of any other holder (a
19: //! Rails or gem setting needs that framework's behaviour, not a replay),
20: //! statements nested in a `configure` block or a `to_prepare` body, and
21: //! the boot hooks themselves (`after_initialize`, `on_load`, …), whose
22: //! run order is the rest of #841's E2.
